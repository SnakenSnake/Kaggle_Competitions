## Workflow

For each competition, I generally follow this process:

```text
Dataset
   ↓
Understand the Data
   ↓
Data Cleaning
   ↓
Exploratory Data Analysis
   ↓
Feature Engineering
   ↓
Train / Validation Split
   ↓
Model Training
   ↓
Evaluation
   ↓
Experimentation
   ↓
Kaggle Submission
```

The goal is not only to produce a submission, but also to understand why a particular approach performs better or worse.
